Prompt to use✖
The following prompt is to be used to convert attached articles into a table or csv file.
Each source is either an article written by an author or a news article. If it is an article, select the 10 most important statements (do not translate them), then categorize those statements. The "actor" is the article's author. If it is a news article, identify the persons/actors mentioned and their statements (do not translate them), then categorize those statements. In both cases, put everything into a table with columns for Actor, Statement, and Category. Since the table will be converted into a CSV file, ensure every row has all three columns filled. If any category consists of fewer than 4 statements, merge it with another category.
